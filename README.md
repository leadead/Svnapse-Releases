# Svnapse

原生 macOS SVN 客户端。内置 Subversion，开箱即用，不需要 Homebrew 或 svn 命令；常用与进阶操作全部在 App 内完成。

## 功能

- **日常操作**：检出、更新、提交、差异、冲突解决、日志
- **分支与进阶**：分支、标签、合并、仓库浏览器、暂存、Externals、稀疏检出
- **协议**：http、https、svn、svn+ssh、file
- **iCloud 同步**：仓库、账号、密钥和设置在多台 Mac 间同步；密码和私钥只保存在 iCloud 钥匙串
- **端侧 Apple 智能**：生成提交说明、总结提交，数据不离开本机

界面支持简体中文、English、日本語、Tiếng Việt。

## 下载与安装

系统要求：macOS 27 及以上，Apple Silicon。

1. 下载 [Svnapse.zip](https://github.com/leadead/Svnapse-Releases/releases/latest/download/Svnapse.zip)（[所有版本](https://github.com/leadead/Svnapse-Releases/releases)）
2. 解压后把 Svnapse 拖入「应用程序」

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在菜单中选择「检查更新…」。

## 隐私

Svnapse 不采集、不上传任何数据。
